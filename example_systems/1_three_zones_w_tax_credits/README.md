# Three Zones with Tax Credits Example

**Three Zones with Tax Credits**, a one-year example with hourly resolution, is based on the 1_three_zones example and demonstrates how to model investment tax credits (ITC) and production tax credits (PTC) in GenX. The system contains zones representing Massachusetts, Connecticut, and Maine, with ten resources including natural gas, solar PV, wind, and lithium-ion battery storage.

## Tax Credit Policies

### Investment Tax Credits (ITC)
Two ITC policies are defined in `policies/Investment_tax_credits.csv`:
1. **Solar ITC (30%)**: Provides a 30% credit on capital investment costs for solar PV resources
2. **Wind ITC (26%)**: Provides a 26% credit on capital investment costs for wind resources

Resource eligibility is specified in `resources/policy_assignments/Resource_investment_tax_credits.csv`.

### Production Tax Credits (PTC)
Two PTC policies are defined in `policies/Production_tax_credits.csv`:
1. **Wind PTC ($26/MWh)**: Provides $26/MWh for energy generated by wind resources
2. **Solar PTC ($13/MWh)**: Provides $13/MWh for energy generated by solar resources

Resource eligibility is specified in `resources/policy_assignments/Resource_production_tax_credits.csv`.

## How Tax Credits Work

**Investment Tax Credits (ITC):**
- Applied to the annualized capital investment cost of new capacity
- Calculated as: ITC_Rate × Investment_Cost × New_Capacity
- Reduces the effective upfront cost of new capacity investments
- Reflected in the objective function as a credit (negative cost)

**Production Tax Credits (PTC):**
- Applied to energy generation on an annual basis
- Calculated as: PTC_Rate × Energy_Generated × Hours
- Provides ongoing subsidy for production from qualifying resources
- Reflected in the objective function as a credit (negative cost)

## Running the Example

To run the model, first navigate to the example directory:

- Using a Julia REPL:

```bash
$ julia
julia> cd("example_systems/1_three_zones_w_tax_credits/")
```

- Using a terminal or command prompt:
```bash
$ cd example_systems/1_three_zones_w_tax_credits/
``` 
   
Next, ensure that your settings in `settings/genx_settings.yml` are correct. The default settings use the solver `HiGHS`, time domain reduced input data (`TimeDomainReduction: 1`), minimum capacity requirement policy (`MinCapReq: 1`), and **tax credit policies** (`InvestmentTaxCredit: 1` and `ProductionTaxCredit: 1`). A rate-based carbon cap of 50 gCO<sub>2</sub> per kWh is also specified in the `policies/CO2_cap.csv` input file.

Once the settings are confirmed, run the model with the `Run.jl` script in the example directory:

- Using a Julia REPL (recommended)
```julia
julia> include("Run.jl")
```
- Using a terminal or command prompt:
```bash
$ julia Run.jl
```

Once the model has completed, results will write to the `results` directory.

## Tax Credit Outputs

When tax credits are enabled, the following additional outputs are generated:
- `results/investment_tax_credits.csv`: Shows ITC benefits by policy
- `results/production_tax_credits.csv`: Shows PTC benefits by policy
- `results/costs.csv`: Includes `cITCBenefit` and `cPTCBenefit` rows showing total tax credit benefits
